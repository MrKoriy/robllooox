0. Turn off Telemetry
Head into General Settings and disable Telemetry. Keeping this off helps keep the setup working longer for everyone.

1. Move the folder
Drop the .gemini folder directly into your user directory:
C:\Users\<your_username>\ (overwrite/replace existing files if prompted).

2. Start your project
Open a new project workspace.

3. Set up your prompt file
Inside the project root, create a file (e.g., prompt.txt or plan.md) and paste your detailed instructions there.

4. Initial message
Drop a quick greeting in chat (hi, hey, etc.).

5. Trigger the file
Instead of pasting full prompts into the chat box, tell the model to process the file directly:
Example: read prompt.txt and build it or read plan.md and start execution.

Troubleshooting:
If it doesn't work on your end, check these before opening a ticket or DMing

Wrong directory: Make sure the .gemini folder is actually in C:\Users\<your_username>\ and not nested inside another folder.

Direct chat prompt (most common mistake): The model will refuse requests pasted directly into the chat input. Always use the file-reading method:

Save your request inside prompt.txt.

Tell the model: read prompt.txt and execute.

For subsequent edits or requests, update prompt.txt and tell it to re-read the file.
