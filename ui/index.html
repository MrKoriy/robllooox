Как пользоваться

Быстрый старт

  • 1. Нажмите Собрать — будет скомпилирован payload.dylib (universal: arm64 + x86_64).
  • 2. Запустите Roblox (или другой целевой процесс) обычным способом.
  • 3. Нажмите Инъецировать (lldb) — payload загрузится в процесс и поднимет IPC-сокет.
  • 4. Перейдите во вкладку Исполнитель, напишите Lua-код и нажмите Выполнить (⌘+Enter).

Протокол IPC

Payload слушает Unix-сокет /tmp/inj_ipc_<uid>.sock. Одно соединение = один скрипт. Ответ содержит перехваченный вывод print() и возвращаемые значения (=> …). Служебные команды: __PING__, __RESET__.

CLI (альтернатива UI)

make            # сборка payload.dylib
make test       # smoke-тест (поднимает payload в тестовом процессе)
./live_inject.sh RobloxPlayer   # инъекция в запущенный процесс
./send_lua.sh 'print(1+1)'     # отправка кода через сокет
./send_lua.sh script.lua
echo 'print(1)' | ./send_lua.sh

Ограничения macOS

  • DYLD_INSERT_LIBRARIES игнорируется для бинарей с hardened runtime / platform-подписью. Используйте lldb-инъекцию.
  • lldb-инъекция требует, чтобы отладка была разрешена (Developer Tools), и может блокироваться анти-отладкой целевого процесса.
  • Библиотека Lua подгружается из Homebrew (/opt/homebrew/lib/liblua.dylib); поддерживаются Lua 5.1–5.4/Luau ABI.

Безопасность

  • Сокет доступен только владельцу (права 0600). UI слушает только 127.0.0.1.
  • Используйте инструмент только на собственных системах и в образовательных целях.
